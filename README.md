# 1. О проекте

**Генератор паролей** — это утилита командной строки, которая создаёт **криптостойкие пароли** на основе заданных пользователем правил. Проект решает проблему использования слабых паролей типа `123456` или `qwerty`. 

Цель проекта — предоставить простой, но гибкий инструмент для генерации паролей любой сложности, который можно использовать в личных целях или интегрировать в другие системы.

> **Важно:** Пароли генерируются **локально** и не передаются по сети.  
>> *Никогда не используйте один пароль для разных сервисов.*  
>>> ***Рекомендуемая длина пароля — от 12 символов.***

## 2. Возможности
- 🎲 Генерация паролей длиной от 6 до 64 символов
- :capital_abcd: Настраиваемые наборы символов:
  - Заглавные латинские буквы (A-Z)
  - Строчные латинские буквы (a-z)
  - Цифры (0-9)
  - Спецсимволы (!@#$%^&*)
1. 🚫 Исключение похожих символов (например, `1`, `l`, `I`, `0`, `O`)
2. 📋 Автоматическое копирование в буфер обмена
3. 🌐 Веб-интерфейс (в разработке)

### 2.1 Технические характеристики

| Параметр | Значение |
|:----------|:----------|
|Язык программирования|Python|
|Длина пароля|6-64 символа|
|Поддержка спецсимволов|Да (!@#$%^&*)|
|Исключение похожих символов|Опционально|

Генератор пароля выглядит так:
```python
gen = Generator(length=16, use_digits=True, use_special=True)
password = gen.generate()
print(f"Ваш пароль: {password}")  # Пример вывода: "K#8$mQp2&vL!zR7x"
```
