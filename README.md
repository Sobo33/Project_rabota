# 1. О проекте

**Генератор паролей** — это утилита командной строки, которая создаёт **криптостойкие пароли** на основе заданных пользователем правил. Проект решает проблему использования слабых паролей типа `123456` или `qwerty`. 

Цель проекта — предоставить простой, но гибкий инструмент для генерации паролей любой сложности, который можно использовать в личных целях или интегрировать в другие системы.

> **Важно:** Пароли генерируются **локально** и не передаются по сети.  
>> *Никогда не используйте один пароль для разных сервисов.*  
>>> ***Рекомендуемая длина пароля — от 12 символов.***

- 🎲 Генерация паролей длиной от 6 до 64 символов

  - Спецсимволы (!@#$%^&*)

2. 📋 Автоматическое копирование в буфер обмена

### 2.1 Технические характеристики

| Параметр | Значение |
|:----------|:----------|
|Язык программирования|Python|
|Длина пароля|6-64 символа|
|Поддержка спецсимволов|Да (!@#$%^&*)|
|Исключение похожих символов|Опционально|

Генератор пароля выглядит так:
```python
gen = Generator(length=16, use_digits=True, use_special=True)
password = gen.generate()
print(f"Ваш пароль: {password}")  # Пример вывода: "K#8$mQp2&vL!zR7x"
```

**Контрольные вопросы**:

1. *Чем отличается вложенная цитата от обычной?*

Вложенная цитата находится внутри другой цитаты и обозначается двумя знаками > подряд (>>), а обычная — только одним.

2. *Как сделать сноску в Markdown и где она отображается?*

Сноска делается так: [^1] в тексте, а внизу страницы — [^1]: Текст сноски. Отображается обычно в конце документа или страницы.

3. *В чём разница между - [ ] и - [x] в списках задач?*

[ ] означает невыполненную задачу, а - [x] — выполненную, и в некоторых интерфейсах они визуально различаются.

1. *Какие два способа вставки эмодзи вы знаете?*

Можно скопировать эмодзи из таблицы символов напрямую в текст или использовать HTML-код

5. *Зачем нужны HTML-вставки? Приведите пример.*

HTML-вставки нужны для расширения возможностей Markdown, например, чтобы поменять отображение текста на странице div align="center"

6. *Почему важно использовать правильные имена для внутренних ссылок (якорей)?*

Правильные имена якорей (без пробелов, уникальные) нужны, чтобы ссылка точно вела на нужное место, иначе браузер не найдёт заголовок.

7. *Что произойдёт, если в таблице окажется разное количество столбцов в разных строках?*

Таблица отобразится некорректно: лишние данные могут «съехать» или превратиться в мусор, а парсер может проигнорировать строку.
